# 포트폴리오 TASK 로드맵

## 문서 책임

현재 저장소와 승인 기록으로 확인된 TASK 구간의 상태와 직접적인 진행 순서만 기록한다.
외부 로드맵 전체를 복사하지 않으며 완료 사실과 향후 계획을 구분한다.

> 현재 문서는 전체 완료 TASK 목록이 아니라 TASK-031, TASK-059와 후속 계획을 중심으로 한 검증된 구간이다.
> 나머지 완료 TASK는 Issue, PR, commit 또는 별도 승인으로 확인된 뒤 추가한다.

## 상태 기준

- `완료`: Issue, PR, commit 또는 검증 결과로 완료 근거가 확인됨
- `진행 중`: Issue와 작업 브랜치가 확인됐으나 완료 검증 전
- `계획`: 선행 TASK 완료와 사용자 승인 후 시작할 예정

```text
→ TASK-028
→ TASK-043
```

TASK가 완료돼도 후속 TASK를 자동으로 시작하지 않는다.
완료 판정과 다음 TASK 착수는 사용자가 승인한다.

## TASK 학습 종료 기준

각 TASK는 구현 완료만으로 종료하지 않는다. 다음 질문에 근거를 들어 답할 수 있어야 한다.

1. 어떤 문제를 해결하기 위해 도입했는가
2. 기존 방식의 한계는 무엇인가
3. 선택 가능한 대안은 무엇인가
4. 현재 프로젝트에서 이 방식을 선택한 이유는 무엇인가
5. 동시성, 트랜잭션과 장애 상황에서 어떤 문제가 발생할 수 있는가
6. 테스트로 무엇을 검증했는가
7. 프로젝트가 확장될 경우 현재 설계의 한계는 무엇인가
